# How to Install DLSS 5 on Windows

DLSS 5 is NVIDIA's latest generation of neural rendering technology for GeForce RTX graphics cards. It adds AI-powered lighting and material improvements while working together with existing DLSS technologies such as Super Resolution, Frame Generation and Ray Reconstruction.

This guide explains how to install and enable DLSS 5 on a Windows gaming PC.

> **Important:** DLSS 5 support depends on the game and graphics hardware. NVIDIA currently lists GeForce RTX 50 Series GPUs for DLSS 5, and the technology is integrated into supported games rather than being a universal standalone application.

## System Requirements

For the current official DLSS 5 implementation, you should have:

* Windows 10 or Windows 11
* NVIDIA GeForce RTX 50 Series graphics card
* Latest NVIDIA graphics driver
* A game with DLSS 5 support
* Updated NVIDIA App

DLSS 5 is currently focused on GeForce RTX 50 Series hardware. NVIDIA has said that it plans to expand official support to GeForce RTX 40 Series hardware in the future.

## Step 1 — Update Your NVIDIA Driver

Open the NVIDIA App and check for available driver updates.

Install the latest Game Ready Driver for your graphics card.

Restart Windows after the installation if the NVIDIA installer requests it.

The DLSS 5 launch for NBA 2K27 was accompanied by a new NVIDIA Game Ready Driver, which is why keeping the graphics driver current is an important first step.

## Step 2 — Install or Update NVIDIA App

Make sure the NVIDIA App is installed and updated.

The NVIDIA App provides access to NVIDIA graphics settings and can also update supported games to newer DLSS technologies.

Do not confuse DLSS 5 with an ordinary Windows application. In supported games, the technology is part of the game's graphics pipeline.

## Step 3 — Install DLSS 5 Files

If you are using a supported DLSS 5 package, follow the installation instructions included with that package.

Do not replace random NVIDIA DLL files downloaded from unknown websites.

For the safest setup, use NVIDIA-provided software and files supplied by the game developer whenever possible.

## Step 4 — Start a DLSS 5 Compatible Game

Launch a game that supports DLSS 5.

NVIDIA's first DLSS 5 implementation launched with **NBA 2K27** in September 2026.

Open the game's:

**Settings → Graphics**

Look for an option named:

```text
DLSS Neural Rendering
```

NVIDIA identifies this as the in-game setting for DLSS 5.

## Step 5 — Enable DLSS Neural Rendering

Turn on:

```text
DLSS Neural Rendering
```

Depending on the game, you may also have access to other DLSS options:

* DLSS Super Resolution
* DLSS Frame Generation
* DLSS Multi Frame Generation
* DLSS Ray Reconstruction
* NVIDIA Reflex
* Ray Tracing
* Path Tracing

DLSS 5 is designed to work alongside ray tracing and path tracing rather than replacing them.

## Step 6 — Restart the Game

Some graphics settings require a restart.

After enabling DLSS 5:

1. Apply the graphics settings.
2. Exit the game.
3. Start the game again.
4. Return to the graphics menu.
5. Confirm that DLSS Neural Rendering remains enabled.

## How to Check if DLSS 5 Is Working

The easiest way to check is to open the game's graphics settings and confirm that **DLSS Neural Rendering** is enabled.

You can also compare the same scene with the feature enabled and disabled.

Look for changes in:

* Lighting
* Materials
* Reflections
* Surface detail
* Character appearance
* Image stability
* GPU utilization
* Frame rate

DLSS 5 uses 3D-Guided Neural Rendering to add lifelike lighting and material detail while preserving the structure of the rendered scene.

## DLSS 5 and RTX 50 Series

DLSS 5 is currently designed for GeForce RTX 50 Series GPUs.

NVIDIA's current DLSS documentation lists 3D-Guided Neural Rendering as an RTX 50 Series feature.

Examples include:

* GeForce RTX 5090
* GeForce RTX 5080
* GeForce RTX 5070 Ti
* GeForce RTX 5070
* Other GeForce RTX 50 Series desktop GPUs
* Supported RTX 50 Series laptop GPUs

Hardware support should always be checked against NVIDIA's current documentation because compatibility can change as new products and software versions are released.

## Can DLSS 5 Be Used With Other DLSS Features?

Yes.

DLSS 5 is designed to complement existing NVIDIA technologies.

A supported game can potentially combine DLSS 5 with:

* Super Resolution
* Frame Generation
* Multi Frame Generation
* Ray Reconstruction
* Ray Tracing
* Path Tracing
* NVIDIA Reflex

NVIDIA states that DLSS 5 can work with Super Resolution, Frame Generation and Ray Reconstruction.

## Troubleshooting

### DLSS Neural Rendering Is Missing

Check the following:

1. Your GPU model.
2. Your NVIDIA driver.
3. Your NVIDIA App version.
4. Your game version.
5. Whether the game officially supports DLSS 5.

If the setting is missing, the game may simply not have DLSS 5 support yet.

### DLSS 5 Download Does Not Work

Make sure the download completed correctly.

If Windows reports that a downloaded file is unsafe or corrupted, do not disable Windows security simply to force the installation.

Instead, verify that the file came from a trusted source.

### I Have an RTX GPU but Cannot Enable DLSS 5

Not every RTX graphics card supports every DLSS feature.

RTX 20, RTX 30 and RTX 40 GPUs support various DLSS technologies, but DLSS 5's 3D-Guided Neural Rendering currently targets RTX 50 Series hardware.

### DLSS 5 Does Not Increase FPS

DLSS 5 is primarily a neural rendering and visual-quality technology.

It should not be confused with technologies whose primary purpose is frame generation or resolution scaling.

Your final performance depends on the game, resolution, GPU, graphics settings and the other DLSS features enabled.
